# 永嘉麦饼

## 起源
永嘉麦饼起源可追溯至唐代永嘉花坦村，由朱氏先人创制，迄今已有一千多年历史。最初为方便农人上山砍柴携带干粮，以麦粉包裹咸菜和鲜肉煎烤而成，因味道鲜美逐渐流传。

## 制作工艺
核心步骤包括和面、包馅、成型与烘烤。老师傅坚持老面发酵，梅干菜要经过三蒸三晒达到乌黑油亮，肥肉丁需如黄豆大小均匀以确保油脂渗透。代表性传承人汪永良称“一个好麦饼要经历10多道工序”。

## 非遗与产业
2014年列入温州市级非遗，2023年列入第六批省级非物质文化遗产代表性项目名录。全国永嘉麦饼店从2019年初100余家增至500余家，产业年产值从1.2亿元增至2024年6.1亿元。温州民俗中，旧时女子出嫁，母亲必在嫁妆中放入麦饼模具，寓意持家有道。
