# 谢灵运与楠溪江诗歌语料

## 背景
公元422年秋，谢灵运到永嘉郡（今温州）任太守，在任期间漫游永嘉山水，写下二十余首山水诗，奠定了中国山水诗鼻祖的地位[reference:21]。据现存资料，谢灵运以温州为题材的作品计24首，其中山水之咏21首。

## 核心诗篇

### 《登池上楼》（节选）
潜虬媚幽姿，飞鸿响远音。
薄霄愧云浮，栖川怍渊沉。
进德智所拙，退耕力不任。
徇禄反穷海，卧疴对空林。
衾枕昧节候，褰开暂窥临。
倾耳聆波澜，举目眺岖嵚。
初景革绪风，新阳改故阴。
池塘生春草，园柳变鸣禽。
> “池塘生春草，园柳变鸣禽”为千古名句，南朝钟嵘《诗品》引《谢氏家录》称此语“有神助，非我语也”。

### 《登绿嶂山》（节选）
澹潋结寒姿，团栾润霜质。
涧委水屡迷，林迥岩逾密。
眷西谓初月，顾东疑落日。

## 后世文人引用
- 李白：“谢公宿处今尚在，渌水荡漾清猿啼。脚著谢公屐，身登青云梯。”（《梦游天姥吟留别》）
- 李白：“康乐上官去，永嘉游石门。江亭有孤屿，千载迹犹存。”（《与周刚清溪玉镜潭宴别》）
- 孟浩然：“借问同舟客，何时到永嘉。”
- 苏轼：“自言长官如灵运，能使江山似永嘉。”
