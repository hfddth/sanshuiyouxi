# 桂林阳朔古村落空间

## 阳朔西街
阳朔西街位于广西壮族自治区桂林市阳朔县古镇中心，宽约8米，主街长近800米，略呈东西走向，东接滨江路，西抵蟠桃路，中间与县前街、城中路交汇。西街始建于隋朝，距今已有1400余年历史，是阳朔最古老、最繁华的街道，也是阳朔重要的旅游景点之一。1966年因避讳“西”字曾改称“东风路”，1982年恢复旧名。1984年改造成旅游文化街，1999年至2004年完成保护性整治。街区由“两街两园六巷”构成，占地约28万平方米，建筑呈现“小青瓦、坡屋顶、白粉墙、吊阳台”的桂北民居风格，分布着古道碑林、摩崖石刻20余处文化遗产。街道用本地产槟榔纹大理石铺筑，保留清代砖瓦房、白粉墙红窗的岭南建筑风貌。现存江西会馆、西横街等历史街巷，保持着半商半农的双重性格。西街曾是孙中山先生演讲的地方，艺术大师徐悲鸿也曾居于此。2023年入选第二批国家级旅游休闲街区。

## 兴坪古镇
兴坪古镇位于阳朔县兴坪镇，是桂林历史最为悠久的城邑之一。早在秦朝，这里即为桂林郡所辖地。三国吴甘露元年（265年）设尚安县治于兴坪镇狮子嵅村；晋武帝太康年间（280—289年）改尚安县为熙平县，治址不变。隋开皇十年（590年），废熙平县改置阳朔县，治所由狮子嵅迁往阳朔镇，此处仅作圩集，“熙平”经年深日久渐讹传为“兴坪”。古镇始建于三国吴甘露元年（265年），迄今已有1700多年历史。古镇现存古街、古桥、古戏台、古庙等明清建筑，老街长约1000米，从古镇东南延伸至榕树潭、兴坪码头，各省会馆坐落于此。漓江流经镇西南部20公里，形成九马画山、黄布倒影、莲花岩等八大景区，包含明代腾蛟庵。镇内渔村还留有孙中山1921年造访过的足迹，1998年克林顿总统访问渔村后，古镇国际知名度进一步提升。第五套人民币20元背景图案取材于此地大河背村的元宝山景观。

## 大圩古镇
大圩古镇位于桂林市灵川县境东南部、漓江东岸，距桂林市区约23公里水程，是广西古代“四大圩镇”之一。古镇历史可追溯至汉代形成的小居民点，旧称长安市、芦田市；北宋时已成为商业繁华集镇，南宋末年静江府在此设税官。明永乐年间沿漓江北岸立街设坊，长约五华里，人称“五里古镇”，为明代广西四大圩镇之首。明清时期，大圩已是南北商贾云集之地，各地商人在此建有广东、湖南、江西会馆及清真寺等。清光绪三十一年《临桂县志》称大圩为“水陆码头”。民国初期已形成老圩街、地灵街、隆安街等八条大街，沿江建有鼓楼码头、塘坊码头等13个码头，泊船多达二三百艘，赶圩人数高达1万余人。古镇标志性建筑万寿桥始建于明代，初为木结构三拱板桥，清光绪二十八年（1902年）捐资重建为单拱石桥，全长29.6米，净跨16米，桥面宽6.5米，桥体以大青石块砌筑，1985年被公布为灵川县文物保护单位。

## 桂北民居与宗族村社
桂北民居以“小青瓦、坡屋顶、白粉墙、吊阳台、石板街”为核心特征，常见于阳朔西街、兴坪老街与大圩古镇。建筑多为砖木结构，青砖灰瓦、木质梁柱，屋檐飞翘、雕花窗棂精美，兼具岭南通风防潮功能与湘赣建筑韵律。在村社层面，古镇历史上由官府机构与民间信仰共同维系秩序：明初设芦田市巡检司，清嘉庆六年（1801年）设桂林府盐运水利分府，宗族祠堂与庙宇（如高祖庙、清真寺）承担基层治理与信仰聚合功能。大圩镇因水运便利，形成了以码头—商号—会馆—宗祠为轴线的商贸聚落结构；阳朔西街则保留了“半商半农”的复合型社区形态，街道两旁的清代低矮砖瓦房至今仍承载居住与商业双重功能。
