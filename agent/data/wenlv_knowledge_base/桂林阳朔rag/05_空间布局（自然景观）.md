# 桂林阳朔空间布局（自然景观）

## 漓江与精华游览段
漓江发源于“华南第一峰”猫儿山，流经桂林市，以流域孕育的岩溶山水景观闻名于世。漓江风景区为世界自然遗产地、国家AAAAA级旅游景区、国家重点风景名胜区，是世界上规模最大、风景最美的岩溶山水游览区。漓江精华段位于杨堤至兴坪，全长约20公里，沿途可览九马画山、黄布倒影、元宝山（第五套人民币20元背景图案取景地）等标志性景观。漓江竹筏与游船是核心体验项目，杨堤—兴坪段竹筏漂流可近距离感受喀斯特峰林与翠竹倒影；游船视野开阔，适合全程观赏。兴坪古镇码头、杨堤码头为正规购票点。

## 遇龙河与田园水系
遇龙河素有“小漓江”之称，为漓江在阳朔境内最长支流。遇龙河人工竹筏漂流是阳朔最具代表性的亲水项目，推荐金龙桥至旧县段或水厄底码头至综合码头段，漂流时长约40分钟，可体验数次冲坝乐趣。两岸稻田、凤尾竹与喀斯特峰林相映，晴雨皆宜。沿河十里画廊骑行线路与漂流形成水陆互补，月亮山、大榕树等景点分布于沿线。遇龙河景区2025年1—10月接待游客467万人次，营业额4.34亿元。

## 喀斯特峰林与溶洞奇观
桂林山水以“山青、水秀、洞奇、石美”著称，属典型的热带喀斯特地貌。银子岩为典型层楼式溶洞，以晶莹洁白的钟乳石闻名，洞内“三绝”（音乐石屏、瑶池仙境、雪山飞瀑）与“三宝”展现喀斯特溶洞的鬼斧神工。芦笛岩被誉为“大自然的艺术之宫”，洞内恒温约20℃，钟乳石琳琅满目，适合夏季避暑。阳朔月亮山因山顶穿孔如满月而得名，十里画廊沿线群峰林立，是攀岩、骑行与摄影胜地。阳朔攀岩运动发展成熟，月亮山、金猫洞等岩场常年吸引国内外攀岩者。

## 史前遗址与文化地层
甑皮岩遗址位于桂林市南郊独山西南麓，是一处新石器时代早、中期洞穴遗址，距今约12000—7000年，属华南地区新石器时代早期代表性遗址。遗址包涵主洞、矮洞和水洞，占地面积约300平方米，出土了中国制作最原始的陶器（距今约12000年的“陶雏器”）、最早的石器加工场及上万件石器、骨器、蚌器、角器、牙器和陶器碎片。遗址还出土了距今约一万年的碳化桂花种子及芋头残块，表明甑皮岩人可能已掌握块茎类植物栽培技术。2001年甑皮岩遗址被国务院公布为第五批全国重点文物保护单位，2021年入选国家文物局《大遗址保护利用“十四五”专项规划》，现为国家考古遗址公园。

## 经典游览路线与特色体验
经典两日游路线：第一天漓江竹筏（杨堤—兴坪）+兴坪古镇+十里画廊骑行；第二天遇龙河漂流+银子岩或相公山。特色体验包括：漓江渔火节（夜间渔翁点灯捕鱼）、阳朔攀岩（月亮山、金猫洞等岩场）、《印象·刘三姐》大型山水实景演出（以漓江水域和十二座山峰为舞台背景，2004年3月首演，累计演出超6500场，接待观众近1600万人次）、龙脊梯田与红瑶长发村民族风情游（位于龙胜各族自治县，距桂林市区约90公里）。游览提示：遇龙河漂流需穿凉鞋并备防水袋；溶洞地面湿滑，建议穿防滑鞋并携带薄外套。

## Agent用法提示
本文件内容可用于文旅剧本游的空间动线设计、场景切换与自然谜题构建。漓江精华段与20元人民币背景可作为“地理寻宝”任务的天然打卡点，设置竹筏上的线索投递与水上追逐剧情；遇龙河冲坝体验可设计为“激流递信”或“限时渡河”关卡。喀斯特溶洞（银子岩、芦笛岩）的恒温环境与复杂地形适合“地下迷宫”“古文明遗迹探索”等副本，钟乳石景观可作为光影解谜的机关背景。甑皮岩遗址的万年陶器与桂花种子为剧本提供史前文明线索，可构建“寻找万年智慧圣地”的考古主线。十里画廊骑行与攀岩可转化为竞速或体力挑战任务，《印象·刘三姐》山水实景演出则可作为剧本高潮的“大型实景剧场”节点。
