# 凤凰古城文学记忆与历史人物

## 沈从文与《边城》
沈从文（1902年12月28日—1988年5月10日），原名沈岳焕，字崇文，湖南省湘西凤凰县人，中国著名作家、历史文物研究者。1924年开始文学创作，其代表作《边城》创作于1933年至1934年，首次出版于1934年。小说以20世纪30年代川湘交界的边城小镇茶峒（2005年改名边城镇）为背景，通过船家少女翠翠与船总两个儿子天保、傩送的爱情悲剧，展现湘西民众淳朴善良的人性之美与田园牧歌式的生活图景。作品中“白塔”“渡船”“端午龙舟”“山歌对唱”等意象，成为凤凰及湘西文学符号的核心来源。

沈从文的文学世界深受凤凰水土滋养：柔韧沱江水培养其不屈的抗争精神，清秀听涛山造就其广阔博大的胸怀。他的作品被译成日本、美国、英国、前苏联等四十多个国家的文字出版，两度被提名为诺贝尔文学奖评选候选人。

## 故居与听涛山墓地
沈从文故居位于凤凰古城中营街，坐东朝西，砖木结构穿斗式四合院平房，由前后天井、前屋、正屋、厢房、书房等组成，前后天井均用红岩石块铺设。宅院由其祖父沈宏富于清同治五年（1866年）兴建。

沈从文于1988年5月10日在北京逝世。按其遗愿，骨灰一半撒入沱江，一半于1992年5月10日归葬于凤凰古城东面听涛山。墓地没有凸起的坟冢，也没有华丽的装饰，仅树有一块从南华山运来的天然五彩玛瑙石，高1.9米，厚0.9米，重约6吨。石正面镌刻沈从文手迹：“照我思索，能理解‘我’；照我思索，可认识‘人’。”石背面刻有沈从文妻妹张充和撰写的挽联：“不折不从，亦慈亦让；星斗其文，赤子其人。”将四句话末字连读即为“从文让人”。不远处另有黄永玉题词石碑：“一个士兵要不战死沙场，便是回到故乡。”

## 凤凰历史人物群像
凤凰古城素有“天开图画，人出凤凰”之誉，明清至近代英才辈出：
- **熊希龄**（1870—1937）：字秉三，凤凰县沱江镇人，15岁中秀才、22岁中举人、25岁中进士，曾任中华民国第一任民选总理。后弃政从善，创办香山慈幼院，被誉为“慈善总理”。
- **黄永玉**（1924—2023）：凤凰籍著名画家，凤凰古城中心广场凤凰雕塑的设计者，其题写的“凤凰城·朱镕基·辛巳春”纪念墙亦为古城标志。
- **陈渠珍**（1882—1952）：人称“湘西王”，凤凰县城人，1906年毕业于湖南武备学堂，曾加入同盟会，著有纪实文学《艽野尘梦》，记录其援藏抗英与藏女西原的爱情传奇。
- **田兴恕**：清代钦差大臣、云贵提督，凤凰籍苗族人士，听涛山墓地原址“杜母园”即其为母亲杜氏修建的花园。
- **郑国鸿**：清代抗英名将，凤凰籍，于鸦片战争中抗御英军、捍卫海疆。

## 地名传说与历史文献
凤凰之名源于县城西南一座形似展翅凤凰的山峰。明朝隆庆年间于此山设置军营，称“凤凰营”，自此“凤凰”之名见于史册。后因营、厅、直隶厅、县相沿至今。明清时期，凤凰古城被称为“镇筸”，是西南地区庞大的军事基地与战略要塞。

沱江为凤凰县境内最大河流，其名由宋徽宗于公元1119年赐给五寨司田氏土司对联——“宦流齐国勋臣邑，世守沱江宰相家”——自此得名。该江汇流沅江，经洞庭湖注入长江，被凤凰人视为母亲河。
