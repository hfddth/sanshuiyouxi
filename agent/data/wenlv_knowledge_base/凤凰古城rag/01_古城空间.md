# 凤凰古城空间格局与标志性建筑

## 古城格局与沱江穿城
凤凰古城位于湖南省湘西土家族苗族自治州凤凰县沱江镇，始建于清康熙四十三年（1704年），占地面积约10平方公里，现为AAAAA级旅游景区。古城依山傍水，沱江穿城而过，整体建筑呈阶梯式上升，形成“面江背山、层层叠叠”的空间格局。古城现存文物古建筑68处、古遗址116处、明清时代特色民居120多栋、庙祠馆阁30多座，是中国西南现存文物建筑最多的县之一。2001年被授予“国家历史文化名城”称号，2006年5月25日凤凰古城堡被国务院公布为第六批全国重点文物保护单位。

## 虹桥风雨楼与北门城楼
虹桥原名卧虹桥，始建于明洪武初年，现存桥梁建成于清康熙九年（1670年），民国三年（1914年）重修并改名虹桥。桥长112米，宽8米，高10.2米，为2墩3孔红砂石拱桥，载重量80吨。因建桥所用岩石均为朱红色砂石，桥建成时宛如彩虹卧江，故名卧虹桥。民国年间洪水重创后重修，湘西镇守使田应诏亲题“虹桥”二字，始称“虹桥风雨楼”；现风雨楼为2000年重建，分上下两层，一层为商铺，二层为民俗文化楼收藏书画作品，桥两侧各有12间店铺，中间为3.6米宽的人行长廊。

北门城楼本名“壁辉门”（亦作璧辉门、碧辉门），始建于明嘉靖三十五年（1556年），因军事防御需要将凤凰土城改建为砖城；清康熙五十四年（1715年）又将砖城改建为石城，采用本地红砂条石筑砌。城门楼上有一幅取材于《三国演义》中“古城会”的石雕画。东门城楼始建于清康熙五十四年（1715年），原名“升恒门”，为凤凰古城四大城门之一。古城墙与东门城楼相连，是沱江防御体系的重要组成部分。

## 沱江跳岩与回龙阁吊脚楼群
沱江跳岩始建于清康熙四十三年（1704年），由15个岩墩组成，曾是进出凤凰古城的主要通道之一，在乾嘉苗民起义、辛亥革命凤凰光复起义等历史事件中均为重要通道。回龙阁古街一带的吊脚楼群全长240米，属清朝和民国初期的建筑，是古城最具浓郁苗族建筑特色的古建筑群之一，目前仍居住着十余户人家。吊脚楼细脚伶仃地直立在沱江之中，夜晚灯光倒映江面，是古城最具代表性的视觉符号。

## 名人故居与宗祠会馆
凤凰古城内名人故居与宗祠资源丰富，尤以“凤凰九景”为核心：
- **沈从文故居**：位于中营街，坐东朝西，砖木结构穿斗式四合院平房，由前后天井、前屋、正屋、厢房、书房等组成，前后天井均用红岩石块铺设。宅院由沈从文祖父沈宏富于清同治五年（1866年）兴建。
- **熊希龄故居**：位于古城北文星街小巷里，占地面积800平方米，为极具苗族情调的四合院，系南方古式木瓦建筑风格。
- **杨家祠堂**：始建于清道光十六年（1836年），木质结构四合院，上下两层，占地面积770平方米，由大门、戏台、廊房、正厅组成，是凤凰县24家祠堂中唯一一家在古城内的祠堂。
- **其他**：古城博物馆（陈宝箴世家）、崇德堂（凤凰城内首富古宅）、万寿宫（江西会馆）等共同构成了古城核心人文空间。
