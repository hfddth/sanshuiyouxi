# 徽州非物质文化遗产与民俗风情

## 徽州三雕：刀锋上的建筑史诗

徽州三雕（木雕、石雕、砖雕）是古徽州一府六县区域内具有徽派风格的传统雕刻工艺，世代相传，流程完整，在国内外享有较高声誉。2006年5月20日，经国务院批准列入第一批国家级非物质文化遗产名录，遗产编号VII-37，申报地区为安徽省黄山市与江西省婺源县。木雕方面，清末民初绩溪县胡国宾、汪聚有名噪一时；民国初年黟县宏村承志堂的梁架与门窗分别聘请歙县方子贵师徒5人及黟县程双喜师徒3人雕刻，极为精细。石雕相传余香为清乾隆年间黟县人，歙县北岸吴氏宗祠“叙伦堂”内西湖景石雕拱板即出自黟县余忠臣之手。砖雕由明代徽州窑匠鲍四首创，题材涵盖戏剧、山水与民俗场景。

## 徽剧：京剧源头与舞台活化石

徽剧是京剧的重要源头，清乾隆年间“庆昇”“彩庆”“同庆”“大阳春”等徽班即在婺源搭班演出。嘉庆三年（1798年），武英殿大学士曹振镛回乡祭祖时将其父创立的“华廉”戏班改为“庆昇”班带回婺源。此后20多个徽剧班社在婺源演出，号称“京外四大徽班”。1956年重新成立婺源徽剧团，1959年以《汾河湾》赴京汇报演出获专家好评。2006年，婺源徽剧被列为第一批国家级非物质文化遗产名录。傩舞俗称“鬼舞”，源于原始巫舞，婺源傩舞主要分布在中云镇坑头村、秋口镇长径村等地，春节期间及重要节日表演，以驱鬼逐疫、祈求五谷丰登。

## 徽菜：发酵与腌制的山野哲学

臭鳜鱼堪称徽菜名片，也是国家级非遗。明清时期徽商沿新安江贩鱼至歙县，以木桶加盐铺荷叶运鲜，经七日自然发酵，鱼肉呈蒜瓣状紧实口感。毛豆腐则是黄豆在皖南湿润气候中与毛霉菌共生，表面长出寸许银丝菌丝，经菜籽油煎至金甲皴裂，外酥里嫩，菌香迸发，曾登上纪录片《风味人间》。这两道菜均体现了古代徽州人应对山区粮食与保鲜需求的智慧。

## 鱼灯与节庆民俗

2025年2月11日（农历正月十四），“非遗贺新春·DOU来徽物集”活动在歙县徽州古城举办，现场汇聚近30个非遗展位。夜幕降临时，黄山歙县的汪满田鱼灯、瞻淇鱼灯、渔梁鱼灯首次同框巡游，成为活动最大亮点。鱼灯巡游源自当地“嬉鱼灯”民俗，祈求年年有余、村落平安，已被纳入春节非遗展演体系。歙砚、徽墨作为文房四宝中的顶级品类，亦是徽州工艺的活态名片，至今仍由非遗传承人沿用古法制作。

## Agent用法提示

剧本游可设置“非遗传承人”系列NPC：三雕匠人向玩家发布“辨认门楼砖雕剧目”挑战；徽剧班主邀请玩家完成一场微缩徽剧《水淹七军》的唱腔排序任务；鱼灯巡游场景可设计为夜间限时活动，玩家需在规定时间内集齐“汪满田、瞻淇、渔梁”三盏鱼灯，解锁隐藏剧情。臭鳜鱼与毛豆腐可作为“食材收集”支线，玩家需在古村市集辨别发酵程度正确的食材，交由徽菜大厨NPC烹制，触发味觉相关的剧情回忆片段。
