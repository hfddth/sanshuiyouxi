# 徽州文学、历史与人物语料

## 新安理学与朱熹的徽州渊源

新安理学是中国思想史上曾产生重大影响的学派，其奠基人程颢、程颐及集大成者朱熹，祖籍均在徽州（今黄山市屯溪区篁墩），因徽州前称为新安郡，故以“新安”定名。朱熹那首家喻户晓的《观书有感》（又名《咏方塘》）——“半亩方塘一鉴开，天光云影共徘徊。问渠那得清如许？为有源头活水来。”——相传与徽州水域意象密切相关。理学家对理欲、心物、义利关系的逻辑论证，提升了徽州文化的理性思维，也深刻影响了徽派建筑、宗族制度与商道伦理。

## 方志与文学遗产：《新安志》

南宋淳熙二年（1175年），徽州歙县呈坎人罗愿（1136—1184）历时三年编纂完成《新安志》，至今已近850年历史。罗愿字端良，号存斋，乾道二年（1166年）进士，博学好古，文章效仿秦汉风格，连朱熹都“特称重之”，誉其“有经有纬，骨实意丰”。朱熹还曾应邀为《罗氏族谱》作序，称誉呈坎为“呈坎双贤里，江南第一村”。《新安志》是现存最早的一部徽州地区总志，体例严谨，保留了大量南宋以前的地理、物产、人物与民俗记录，是研究徽州历史地理的核心文献。罗愿另著有《尔雅翼》《鄂州小集》等。

## 新安画派：从明末到近现代

新安画派是明末清初活跃于徽州的绘画流派，奠基者包括明代休宁人丁瓒、丁云鹏父子及歙人李流芳等。该画派以黄山、新安江为创作母题，风格简淡清峻，强调笔墨逸趣。近现代画坛泰斗黄宾虹（祖籍安徽歙县）承其脉络，在墨法上大胆革新，摆脱元以后干墨皴擦的枯硬风格，被誉为“中国画坛泰斗”，著有《中国名画集》《艺观》等。徽州自宋至清共建有书院、精舍260多所，社学明初有462所，清康熙时达562所，文风昌盛，为新安画派及整体学术氛围提供了土壤。

## 近现代名人：陶行知与胡适

陶行知（1891—1946），原名文濬，安徽歙县人，我国近代伟大的教育家、思想家。他先后在南京汇文书院、金陵大学、美国伊利诺伊大学和哥伦比亚大学求学，主修教育。1927年创办南京晓庄师范，提出“生活即教育”“社会即学校”“教学做合一”的生活教育理论体系。毛泽东称赞他为“伟大的人民教育家”，宋庆龄尊称其为“万世师表”。联合国确定的世界十大文化名人中，陶行知位列第一。

胡适（安徽绩溪人）则是新文化运动的领军人物，二者均出自徽州文脉。此外，晚清“红顶商人”胡雪岩（徽州绩溪县人，13岁外出谋生）、晚清货币理论家王茂荫（歙县人，马克思《资本论》中唯一提到的中国人）、近代思想家戴震（休宁人）等，共同构成了徽州人物群像。

## 徽商文学叙事

徽商是中国十大商帮之一，明清时期称雄中国商界500余年，有“无徽不成镇”“徽商遍天下”之说。民间俗语“前世不修，生在徽州；十三四岁，往外一丢”既是徽州人生存困境的写照，也是徽商崛起的集体记忆。徽商发迹后返乡大兴土木、建楼院、修祠堂，留下了宏村承志堂、西递牌坊群等物质遗产，也催生了大量家族传记、行商日记与家训文献，成为剧本游中“商道抉择”与“家书解谜”的优质素材。

## Agent用法提示

剧本游可设计“朱熹遗墨”主线：玩家在呈坎古村寻找《新安志》散佚的附录残页，需通过解谜罗愿与朱熹的往来书信密码，逐步还原南宋徽州水系图。新安画派适合作为“画中藏图”副本——玩家在黄宾虹风格的山水画局部发现隐藏路线，或需临摹一幅新安画派简笔山水以触发NPC画痴的认可。陶行知的“生活即教育”理念可转化为“晓庄试炼”互动关卡：玩家在古村私塾完成“教与做”结合的任务链（如向NPC学做歙砚、再向孩童传授步骤）。徽商家书则可作为碎片化叙事载体，玩家在祠堂密室、货栈阁楼中搜集，拼合出一部徽商家族的兴衰史。
