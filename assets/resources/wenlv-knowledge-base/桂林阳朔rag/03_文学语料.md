# 桂林阳朔文学语料

## “桂林山水甲天下”的最早出处
南宋嘉泰元年（1201年），广西提点刑狱王正功（字承甫，四明人，今浙江宁波）在乡试放榜次日，于桂林独秀峰读书岩举办鹿鸣宴，为桂林中举的十一人祝贺。席间王正功依古礼歌咏《诗经·小雅·鹿鸣》并作诗两首，其第二首诗首句为“桂林山水甲天下，玉碧罗青意可参”。该诗句成为后世称颂桂林景观的经典语句。石刻高115厘米、宽64厘米，因长期受流水侵蚀结垢覆盖而失载于史籍，1983年经文物工作者清理后重现，确认为该名句的最早出处，现藏于桂林市桂海碑林博物馆。摩崖石刻的重新发现，将“桂林山水甲天下”的文献源头从泛化的民间口碑锚定于南宋庆元—嘉泰年间的官方宴飨场景。

## 韩愈与唐宋咏桂诗群
唐代诗人韩愈在《送桂州严大夫》中写道：“苍苍森八桂，兹地在湘南。江作青罗带，山如碧玉篸。户多输翠羽，家自种黄甘。远胜登仙去，飞鸾不假骖。”此诗将桂林山水比作“青罗带”与“碧玉篸（簪）”，至今仍是描写桂林最具审美高度的诗句。韩愈开宗明义以“苍苍森八桂”将“八桂”引入诗行，使“八桂”成为桂林乃至广西的代称。与韩愈同为唐宋八大家的柳宗元赴任柳州刺史途中亦曾小住桂林，留下相关诗迹。宋人陈孚、张孝祥等亦有描绘漓江烟雨、独秀峰雄姿的篇什，形成唐宋以来咏桂诗群。

## 刘三姐传说与地方文献
刘三姐传说最早见于南宋王象之《舆地纪胜》里的《三妹山》，后世在《宜山县志》《庆远府志》《广东新语》及清代屈大均、谭敬超等人的诗文中多有记载。传说中刘三姐为唐代农家女，12岁能通经传，“指物索歌，开口立就”，有“歌仙”之誉；因抗拒逼婚，与情人张伟望出奔，民间传说是双双成仙。刘三姐故事在岭南壮、汉、瑶、苗、侗、仫佬、毛南等民族中广泛流传，有刘三妹、刘三娘、嘹三妹等多种称呼，其形象是各民族交往交流交融的共同文化遗产。1958年《刘三姐彩调剧》创作组经民间采风，认定刘三姐是广西罗城人；1961年长春电影制片厂摄制的电影《刘三姐》使这一传说家喻户晓。

## 徐霞客与历史名人游踪
明崇祯九年（1636年），地理学家徐霞客开始最后一次壮游，次年抵达桂林，在日记中详细记载了漓江两岸岩洞、村落与山川形势，其《粤西游日记》是研究明末桂林历史地理的第一手文献。徐霞客在靖江王府记载了结坛礼“梁皇忏”、置栏演《木兰传奇》的戏曲盛况，称“不数见之盛举”。近现代历史上，孙中山于1921年北伐途中在阳朔西街演讲，并造访兴坪渔村；徐悲鸿曾在西街居住写生；150多个国家的领导人曾在此留下足迹。这些人物游踪构成桂林山水人文景观的叠加叙事。

## Agent用法提示
本文件内容可用于文旅剧本游的文案润色、任务谜题与氛围营造。王正功鹿鸣宴石刻可作为“科举宴饮”剧本的核心线索，设计摩崖石刻拓片寻宝、诗句补全机关；韩愈“江作青罗带，山如碧玉篸”等名句可直接用于场景描述、地图标注与NPC吟咏台词。刘三姐传说适合构建“歌仙遗珍”主线，玩家通过收集不同民族版本的口传碎片，还原唐代歌仙身世。徐霞客游记文本可转化为“跟着霞客游漓江”的打卡任务，将明末地理考察路线与现代游览点位对应，赋予剧本学术考古气质。
