# 凤凰古城非物质文化遗产与民俗风情

## 国家级非遗与传统手工艺
凤凰县非物质文化遗产类型丰富多样，目前拥有非遗项目17大类808项，已列入国家级、省级、州级、县级的项目共76个，项目传承人109人。其中，苗族银饰锻制技艺于2006年（第一批）和2011年（第三批）被列入国家级非物质文化遗产名录，申报地区包括湖南省凤凰县。凤凰蜡染与蓝印花布印染技艺亦列入第一批国家级非物质文化遗产扩展项目名录，遗产发现地为湘西州凤凰县，代表性传承人包括刘贡鑫等。土家织锦和苗族银饰制作技艺同样入选国家级非遗，是湘西少数民族服饰文化的核心载体。

## 传统戏曲与舞蹈
傩堂戏源于商周时期的傩祭仪式，至今已流传3000多年，是傩祭法事结束后“开洞娱人”唱的戏，演员戴着神秘庄严的傩戏面具说着唱词上场，保留半堂戏（12个剧目）与全堂戏（24个剧目）之分。凤凰古城及周边保留湘西千年巫傩文化，常设巫傩面具舞蹈巡游与沉浸式民俗演艺。苗族鼓舞亦为国家级非物质文化遗产，是苗族节庆与祭祀中的核心表演形式，鼓点与舞蹈结合，气势恢宏。

## 民俗节庆与社交习俗
苗族传统节庆体系完整，主要包括：
- **四月八**：苗族重要传统节日，纪念苗族英雄与祖先，通常举行祭祀、歌舞与斗牛活动。
- **赶秋节**：一般在每年立秋前后举行，节会主体为大型祭祀活动，包括迎秋、祭秋、闹秋等环节，被誉为“中国农耕文明的现代遗存”，也是苗族男女青年交往、定情的主要场景。
- **边边场**：苗族青年男女的传统对歌约会习俗，在特定场日聚于城郊或河畔对歌、赠物、定情。
- **六月六**、**苗年**：均伴有盛大的祭祀、歌舞与聚会活动。

土家族亦有**土家赶年**习俗，因历史上除夕出征抗倭的典故，形成了提前一天吃年夜饭的传统。此外，苗族服饰分东部挑花服饰与西部银饰盛装，凤凰县境苗族喜用花帕，女装以青、蓝、白印花布为主，佩戴银铜饰。

## 地方饮食与风味
凤凰及周边湘西风味以酸辣鲜香为特征，代表性饮食包括：
- **血粑鸭**：鸭肉与糯米粑同炖，为古城最具代表性的招牌菜。
- **米豆腐**：酸辣开胃，是当地常见小吃。
- **酸汤鱼**、**酸萝卜**：体现苗族嗜酸传统。
- **腊肉**、**包谷酸五花肉**、**糍粑**、**乾州鸭子**：湘西传统节庆与日常主食。
- 各街巷老店多经营上述菜品，部分店铺历史超过二十年，需现杀现做。
